# SOC-001 – Windows Authentication Investigation

## Objective

Investigate Windows authentication activity using Splunk Enterprise to establish a baseline of successful and failed logons using the Boss of the SOC (BOTS) v3 dataset.

---

## Role

Junior SOC Analyst

---

## Dataset

- Boss of the SOC Dataset Version 3 (BOTS v3)

---

## Tools Used

- Splunk Enterprise
- Windows Security Event Logs

---

## Investigation Summary

In this investigation, I analyzed Windows Security Event IDs 4624 (successful logon) and 4625 (failed logon) to establish an authentication baseline. I used Splunk Enterprise to review authentication activity, identify successful and failed logons, and document my findings using an evidence-based investigation approach.
